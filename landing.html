THE SHORT VERSION

Less inbox triage.
More actual work.

MailAgent classifies email by priority, filters out noise, and drafts responses locally. You choose the provider, the autonomy level, and the moment anything can be sent.

01

See what matters first

Priority scoring, confidence-aware classification, server-side filters, labels, and pagination turn a crowded mailbox into a focused queue.

Explore priority inbox →
02

Draft, don’t blindly send

MailAgent learns your voice and generates drafts, but approval stays with you. Undo windows, idempotency guards, and rate limits protect every send.

Understand the controls →
03

Run it where you choose

Personal mode uses local SQLite and an in-process queue. Connect Gmail or IMAP, use Ollama locally, or bring a cloud key when you explicitly want one.

Read the setup guide →

PRIVACY PROMISE

Your mailbox is not our business.

There is no mandatory MailAgent-hosted backend, central account, telemetry, or analytics. In personal mode, your data stays in local storage and only reaches services you configure.

Read the full promise ↗
LOCAL BY DEFAULTSQLite storage and a local task queue. No cloud dependency required.
ENCRYPTED SECRETSCredentials and AI keys are encrypted with AES-256-GCM and can use your OS keychain.
EXPLICIT CLOUD AIOnly the content required for inference is sent to the provider you select with your own key.
EMERGENCY STOPA built-in kill switch blocks autonomous sending instantly.

YOUR MACHINE. YOUR RULES.

Install it in a few commands.

Clone the repository, install the dependencies, configure your encryption key, and start the dashboard on loopback. No hosted account required.

View source on GitHub ↗
# get the source
git clone https://github.com/Rayed-Hasan/mailagent.git
cd mailagent

# install and start locally
python -m venv .venv
pip install -r requirements.txt
python -m uvicorn mailagent.dashboard.app:app \
  --host 127.0.0.1 --port 8765
